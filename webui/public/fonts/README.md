# Bundled web fonts

Self-hosted so the dashboard works on a LAN with no internet access.

| Family | Files | Source | License |
|---|---|---|---|
| Silkscreen (400, 700) | `silkscreen-*.woff2` | Jason Kottke, via Google Fonts | SIL Open Font License 1.1 |
| Atkinson Hyperlegible Next (400, 700) | `atkinson-*.woff2` | Braille Institute of America, via Google Fonts | SIL Open Font License 1.1 |

Both licenses permit bundling and redistribution with software. The fonts are unmodified subsets (latin, latin-ext).
